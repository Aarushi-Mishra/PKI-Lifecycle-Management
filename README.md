# PKI Lifecycle Management

## Project Overview

A hands-on cybersecurity lab simulating enterprise certificate lifecycle management using OpenSSL and ServiceNow.

The project demonstrates how a Crypto Operations team handles certificate requests, validates CSRs, issues digital certificates, maintains certificate inventory, tracks renewals, and responds to certificate revocation events.

**Environment:** Personal lab using fictional organization and application details. No production systems involved.

## Tools & Technologies

- OpenSSL — PKI and certificate operations
- ServiceNow Developer Instance — Ticket management and asset tracking
- GitHub — Documentation and evidence


## Project Phases

1. Environment Setup
2. Root and Intermediate CA Configuration
3. Certificate Request, Validation and Issuance
4. Certificate Inventory Management
5. Certificate Renewal
6. Certificate Revocation and Incident Handling
7. Lessons Learned

## Skills Demonstrated

Certificate Lifecycle Management | PKI | SSL/TLS | CSR Validation | OpenSSL | ServiceNow | Request Fulfillment | Certificate Inventory | Incident Management | Risk Mitigation


Note: This is a personal learning project using simulated enterprise workflows. All actions are performed in a non-production environment.
